# Aevis System Wallpapers

Official high-resolution system wallpapers collection for the Aevis Desktop Environment.

Part of the **[Project Aevis](https://github.com/project-Aevis)** suite.

## Installation

```shell
mkdir build
cd build
cmake -DCMAKE_INSTALL_PREFIX=/usr ..
make
sudo make install
```

Wallpapers are installed into `/usr/share/wallpapers/aevis/`.
